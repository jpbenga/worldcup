# Road to the Trophy Official View Model V2.15

`road_to_the_trophy_official_view_model_v2_15.json` is the promoted V3 contract adapted to the existing Tournament Atlas. It exposes the official public engine name, 50,000 simulation count, one representative coherent tournament, projected winner and final, twelve fully traversable groups, five knockout rounds, team paths, and contextual match explanations.

The view model is reconstructed from the V2.14 complete-tournament simulation results and representative path. Group tables are recalculated from that path, knockout probabilities come from the V3 head-to-head match model, and every displayed path is internally coherent. The legacy view model remains available only for audit. The official model keeps the Atlas data shape so visual navigation and interaction remain stable while the underlying scenario becomes V3.
