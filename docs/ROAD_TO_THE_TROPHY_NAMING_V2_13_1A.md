# Road to the Trophy Naming V2.13.1A

**Road to the Trophy** est le nom produit officiel de l'expérience consacrée
au chemin vers le titre mondial. Il remplace le libellé générique
`Simulation` dans la navigation, les appels à l'action et le header de la
feature. Le sous-titre public est **Le chemin vivant vers la Coupe du monde
2026**.

La route technique `/simulation` est conservée afin de ne casser aucun lien,
test ou favori existant. Le mot simulation peut également rester dans les
scripts backend, les noms de fichiers JSON, les contrats TypeScript et les
documents techniques. Il décrit correctement le mécanisme interne.

Road to the Trophy doit être visible sur la home, dans la navigation de la
page Transparence et en tête de la route `/simulation`. SimuAI reste le nom du
moteur côté produit. Cette séparation permet un langage mémorable pour
l'utilisateur tout en conservant les conventions techniques du dépôt.
