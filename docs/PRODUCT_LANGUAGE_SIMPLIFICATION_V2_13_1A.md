# Product Language Simplification V2.13.1A

SimuAI est le nom public du moteur. Le langage visible utilise **Prono
SimuAI**, **Score recommandé**, **Résultat officiel**, **Score en direct**,
**Bilan du prono**, **Scores les plus probables** et **Vainqueur projeté**.

Les champs internes tels que `score_modal`, `candidate`, `proxy` ou les noms de
versions restent inchangés dans les JSON et les services. Ils sont utiles aux
développeurs mais ne doivent pas être nécessaires pour comprendre l'écran.
La variante secondaire est appelée **Variante expérimentale** et n'apparaît
que dans un **Mode labo** replié.

Le terme 1X2 peut rester à côté du libellé explicite Résultat du match. Draw No
Bet reste affiché avec une explication courte : le pronostic est remboursé en
cas de nul. Le mot push disparaît donc du parcours principal au profit de
Remboursé.

Cette simplification garde les concepts sportifs précis tout en retirant les
termes qui demandaient une connaissance préalable du moteur.
