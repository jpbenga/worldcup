# Road to the Trophy V3 Promotion Strategy V2.15

Road to the Trophy must present one official SimuAI tournament scenario, not multiple competing proposals. The visible comparison introduced during candidate review asked the public user to arbitrate a technical migration and made the experience less clear. V3 is therefore promoted as the unique public tournament engine. The former scenario remains archived in generated artifacts and audit documentation, but is no longer loaded or named by the main interface.

This promotion concerns only the tournament journey experience. It does not retrain, replace, or modify `quant_hybrid_v2.2`, which remains the active engine for individual pre-match predictions. The frontend now has one canonical source of truth, `road_to_the_trophy_engine.json`, whose embedded official view model feeds the Atlas. Technical history, backtests, limitations, and the old-engine diagnosis remain available for traceability without competing with the product scenario.
