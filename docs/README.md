Cet index est le point d’entrée de la documentation active. Les documents détaillés d’anciennes itérations restent disponibles dans `archive/`, mais ne représentent pas nécessairement l’état actuel du produit.

## Archives

[`archive/README.md`](archive/README.md) explique le classement historique. Les stratégies d’itération, audits détaillés et release notes anciennes y restent consultables pour préserver la traçabilité sans encombrer la documentation quotidienne.

Règle de maintenance : une nouvelle fonctionnalité doit mettre à jour un document actif existant lorsque possible. Les notes spécifiques à une itération doivent être archivées après validation.
