# Road to the Trophy UI Deconfusion V2.15

The public Road to the Trophy screen no longer displays a current-versus-V3 comparison, scenario toggle, candidate status, under-review language, old-engine warning, or calibration-audit banner. Those elements were useful during technical review but created the impression that the user had to choose among competing answers.

The screen now presents one Scénario SimuAI powered by SimuAI Tournament Engine V3 and one coherent projected journey. The Atlas, zoom, pan, group focus, round focus, team selection, match inspection, and status filters remain intact. Technical comparison and credibility evidence remain in V2.14 audit documents and JSON artifacts. The only public limitation retained is that the knockout mapping is projected until the official FIFA bracket is available.
