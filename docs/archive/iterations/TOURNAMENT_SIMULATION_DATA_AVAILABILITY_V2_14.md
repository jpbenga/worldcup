# Tournament Simulation Data Availability V2.14

The repository supports a credible team-level candidate: 1311 dated historical tournament matches, scores, stages, current Elo ratings, 2026 fixtures, real results and standings. Attack, defense and recent form are derived only from scores and dates. The audit rejects player-quality claims, injuries, future lineups, squad values, odds, broad xG and FIFA ranking because they are absent or too sparse. This limitation prevents a fully contextual player-level model, but it does not prevent a backtestable head-to-head model.
