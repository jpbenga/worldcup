# Score Modal vs 1X2 Favorite Explanation V2.7

The modal score is the single highest-probability cell in the score matrix.
The 1X2 trend sums every home-win cell, every draw cell or every away-win cell.
Those two summaries answer different questions and can legitimately point in
different directions.

For each fixture V2.7 publishes the modal score, active 1X2 favorite and the
highest-probability score compatible with that favorite. For example, Mexico
can be the 1X2 favorite while 0-0 is the most probable individual cell; 1-0
then explains the most probable Mexico-win score.

The interface uses this concise explanation: “Le score modal est la case
individuelle la plus probable. La tendance 1X2 additionne toutes les victoires
possibles.” No probability is adjusted to force visual agreement.
