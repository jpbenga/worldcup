# Match Modal Status UX V2.13.1A

La modal adopte désormais le statut du match dès son header. Pour un match
`finished`, Résultat officiel et le score final occupent la zone centrale entre
les équipes. Le Prono SimuAI initial et le Bilan du prono apparaissent juste
après.

Pour un match `live`, Score en direct et le score courant occupent le centre.
Le Prono SimuAI initial reste visible, tandis qu'un message indique que
l'évaluation finale attend le coup de sifflet final.

Pour un match `upcoming`, la zone centrale présente Prono SimuAI, le Score
recommandé, le favori et la confiance. Aucun score réel n'est suggéré.

Les détails de probabilités, marchés et matrice restent disponibles plus bas.
Le Mode labo est replié par défaut et séparé visuellement du Prono SimuAI.
