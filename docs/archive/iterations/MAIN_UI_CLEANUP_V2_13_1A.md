# Main UI Cleanup V2.13.1A

La home reste centrée sur le tournoi et ne montre plus Provenance, État des
données, Exploration V0.3, Sources réelles explorées ni les résultats de
backtest. Ces blocs avaient une valeur pour le développement et l'audit, mais
ils ralentissaient la compréhension des matchs, des classements et des Pronos
SimuAI.

Les informations techniques ne sont pas supprimées du projet. La route
`/transparence` conserve le scoreboard public, l'historique, les limites et un
Mode labo replié. Les documents du dossier `docs/` conservent les décisions de
source, validations, méthodologies et traces d'expérimentation.

La home présente désormais trois idées simples : le Prono SimuAI avant le
match, le tournoi vivant alimenté par les résultats officiels et le bilan
transparent après le match. Road to the Trophy fournit ensuite le chemin
projeté vers le titre sans encombrer la lecture immédiate des groupes.
