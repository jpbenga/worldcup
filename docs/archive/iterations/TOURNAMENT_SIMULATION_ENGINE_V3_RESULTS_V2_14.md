# Tournament Simulation Engine V3 Results V2.14

V3 generated 50,000 complete tournaments. Each run locks finished real results, simulates every remaining group fixture, recalculates standings, selects the top two and eight best third-place teams, creates a varying projected round-of-32 field and simulates every knockout match with the direct V3 engine. The official 2026 bracket mapping is unavailable, so dynamic seeding is clearly marked non-official. All complete paths were generated and aggregated; 100 coherent paths are persisted for exploration and representative scenario selection.
