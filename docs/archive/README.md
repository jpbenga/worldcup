# Documentation Archive

Les archives conservent la mémoire technique du projet sans la présenter comme documentation active. Elles protègent les décisions, audits, validations et résultats intermédiaires qui expliquent comment SimuMondial a évolué.

- `iterations/` contient les stratégies, contrats et validations propres à une version;
- `audits/` contient les inspections détaillées, analyses de crédibilité et rapports de couverture;
- `release_notes/` contient les notes de livraison historiques.

Pour retrouver une itération, chercher son identifiant (`V2_14`, `V2_15`, etc.) dans ces dossiers ou dans `docs/VALIDATION_LOG.md`. Les documents archivés peuvent décrire des candidats, anciennes interfaces ou moteurs qui ne sont plus actifs. La documentation active commence dans `docs/README.md`.

La règle est de déplacer plutôt que supprimer lorsqu’un document possède une valeur historique. Une suppression n’est acceptable que pour un doublon exact, un fichier vide ou un document remplacé sans information unique, avec justification dans le rapport de nettoyage.
