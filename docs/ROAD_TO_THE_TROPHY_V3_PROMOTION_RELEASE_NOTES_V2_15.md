# Road to the Trophy V3 Promotion Release Notes V2.15

V2.15 promotes Tournament Simulation V3 from reviewed candidate to the official Road to the Trophy engine. The public screen now presents one SimuAI scenario instead of an old-versus-new comparison. It loads the canonical `road_to_the_trophy_engine.json`, which embeds an Atlas-compatible official view model built from the coherent V3 representative path and 50,000 complete tournament simulations.

Candidate and under-review labels, the visible comparator, and the former calibration warning have been removed from the main experience. V3 match explanations remain available in match details. Legacy engines and audits remain available for traceability only. This release changes the tournament simulation experience, not active individual pre-match predictions: `quant_hybrid_v2.2` remains unchanged, with no retraining and no Optuna rerun.
