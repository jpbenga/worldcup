# UI Information Density Review V2.5

The group view remains scannable because each fixture receives only one new
line. No matrix, market grid or explanatory copy is placed directly in group
cards.

The match modal has three levels:

1. Immediate context: modal score, confidence, 1X2 and top scores.
2. Useful derived markets, including a plain-language DNB push definition.
3. Collapsed matrix and transparency details.

The simulation table is intentionally separate because four rank probabilities
plus qualification and elimination cannot remain legible inside the home-page
group cards. Mobile users can horizontally scroll the table without changing
the compact home experience.

Remaining risks are the width of the simulation probability table and the
number of concepts inside the modal. Horizontal table overflow and collapsed
matrix/transparency panels contain those risks; desktop and mobile rendering
still require human review.
